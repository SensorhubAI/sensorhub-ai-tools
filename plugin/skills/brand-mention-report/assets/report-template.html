Methodology

How this report was built

Data source

Every figure in this report is sourced from Sensorhub MCP data for the {{BRAND_NAME}} project (project ID {{PROJECT_ID_SHORT}}). No web search, no scraping, no third-party APIs. If something could not be answered from Sensorhub data, it was excluded rather than estimated.

Period and sample

{{PERIOD_START}} to {{PERIOD_END}}. {{TOTAL_MENTIONS}} total signals tracked in the project across Reddit, LinkedIn, and X. The intent classification, action list, and event analysis pages use a top-scored sample of up to 120 signals (40 per platform) for human reviewability. The SOV co-mention counts use the full project corpus via search queries.

Mention classification

Each signal is bucketed into one of six intent categories: buying intent (category), comparison, pricing complaint, churn / displacement, win / testimonial, and feature / product feedback. The classifier reads the signal title and snippet and assigns the most direct match. Signals that do not fit any bucket are tagged as general industry mention and not counted in the intent grid.

Sentiment

The Sensorhub MCP returns a relevance score (commercial signal strength), not a sentiment score. Sentiment posture per bucket in this report is derived from signal text at analysis time, not from the underlying data feed. This is a directional read, not a calibrated score.

SOV co-mentions

For each top competitor, the report counts signals in the {{BRAND_NAME}} project that also reference the competitor by name. This is a co-mention map (who else shows up next to your brand in the same thread), not a pure share of voice (which would compare absolute mention volumes across separate brand projects). Search queries are capped at 50 results per competitor, so any competitor at exactly 50 is undercounted.

What this report doesn't cover

AI citation visibility (how often the brand is cited inside ChatGPT, Gemini, Perplexity). Sentiment trend lines week-over-week (needs longer history). Author reach scoring per mention. These are on the Sensorhub roadmap and will be added to the skill once the underlying data is available.
